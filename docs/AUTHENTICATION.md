# احراز هویت جوما

لایه سرویس: `src/services/auth/authService.ts`

الان پیاده‌سازی Local است. UI فقط با این سرویس حرف می‌زند تا بعداً Supabase جایگزین شود.

## ثبت‌نام

نام، نام خانوادگی، نام کاربری، موبایل، ایمیل، شغل (فهرست)، رمز، تکرار رمز.

موبایل از حالا در مدل کاربر هست تا بعداً OTP اضافه شود. SMS در این نسخه ارسال نمی‌شود.

## ورود

نام کاربری یا ایمیل + رمز.

## نشست

در Local روی `localStorage` می‌ماند. Logout نشست را پاک می‌کند و مسیرهای `/app` محافظت می‌شوند.

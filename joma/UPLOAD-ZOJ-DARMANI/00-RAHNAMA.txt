راهنمای اضافه کردن فعالیت‌های زوج درمانی به جوما
سایت: https://joma.mirbolouki.com
مخاطب: بدون دانش برنامه‌نویسی

این کار دیتابیس را از نو نمی‌سازد.
ثبت عملکرد فعلی، برنامه‌های در حال اجرا، و حساب کاربران را پاک نمی‌کند.
فعالیت‌های جدید فقط به کتابخانه اضافه می‌شوند.
خودکار وارد برنامهٔ ماه جاری کسی نمی‌شوند؛ هر کس بعداً خودش انتخاب می‌کند.


الف) چه چیزهایی را دانلود کنید
==============================
از همین پوشه این ۵ فایل را دانلود کنید:

1-JOMA_ADDONLY_ACT046_ACT080.sql
2-helpers.php
3-library_official.json
4-library.php
5-home.php

این‌ها را دانلود نکنید و روی هاست نگذارید:
- config.php
- joma.sql
- هیچ پوشهٔ دیگر


ب) قبل از هر کار: بکاپ
=======================
۱. وارد cPanel شوید.
۲. phpMyAdmin را باز کنید.
۳. از ستون چپ، دیتابیس جوما را یک‌بار کلیک کنید (انتخاب شود).
۴. تب Export را بزنید.
۵. Go / Export را بزنید و فایل را در کامپیوتر ذخیره کنید.
۶. File Manager را باز کنید.
۷. پوشه‌ای که سایت جوما در آن است پیدا کنید.
   معمولاً یکی از این‌هاست:
   - public_html
   - joma.mirbolouki.com
   نشانهٔ درست: داخلش فایل index.php و پوشه‌های pages و includes و database باشد.
۸. آن پوشه را انتخاب کنید → Compress → zip را دانلود کنید.


پ) مرحله ۱ — فقط فایل SQL در phpMyAdmin
========================================
۱. phpMyAdmin → همان دیتابیس جوما را انتخاب کنید.
۲. تب Import.
۳. Choose File → فایل 1-JOMA_ADDONLY_ACT046_ACT080.sql
۴. پایین صفحه Go / Import.
۵. باید پیام موفقیت ببینید. اگر خطا آمد، همان‌جا بایستید و به من بگویید.

این فایل فقط ۳۵ فعالیت جدید را اضافه می‌کند.
اگر دو بار اجرا شود، تکراری نمی‌سازد.


ت) مرحله ۲ — جایگزینی ۴ فایل در File Manager
=============================================
مهم: فایل جدید را روی فایل هم‌نام قبلی بگذارید (Overwrite / جایگزینی).
پوشهٔ جدید نسازید. نام فایل را عوض نکنید.

برای هر فایل این کار را بکنید:

فایل دانلودشده              برود دقیقاً اینجا روی هاست
-------------------------    --------------------------------
2-helpers.php                includes/helpers.php
3-library_official.json      database/library_official.json
4-library.php                pages/library.php
5-home.php                   pages/home.php

روش عملی برای هر کدام:
۱. File Manager → پوشهٔ مقصد را باز کنید (مثلاً includes).
۲. Upload.
۳. فایل را انتخاب کنید.
۴. اگر نامش 2-helpers.php است، بعد از آپلود آن را Rename کنید به helpers.php
   یا قبل از آپلود روی کامپیوتر نام را به helpers.php برگردانید (این راحت‌تر است).

پیشنهاد: روی کامپیوتر این ۴ فایل را این‌طور نام‌گذاری کنید، بعد Upload کنید:

helpers.php
library_official.json
library.php
home.php

اگر پرسید Replace / Overwrite → بله.

config.php را باز نکنید و جایگزین نکنید.


ث) مرحله ۳ — چک کردن
=====================
۱. از سایت خارج شوید و دوباره وارد شوید.
۲. بروید کتابخانه فعالیت‌ها.
۳. فیلتر دسته → «زوج درمانی».
۴. باید حدود ۳۵ فعالیت ببینید (از بازسازی صمیمیت عاطفی تا ارزیابی ماهانه سلامت رابطه).
۵. یک ثبت عملکرد قدیمی را باز کنید؛ باید مثل قبل باشد.
۶. برنامهٔ در حال اجرا نباید خودبه‌خود این ۳۵ تا را داخلش داشته باشد.
   اگر بخواهید، بعداً از کتابخانه به برنامه اضافه می‌کنید.


ج) اگر چیزی خراب شد
====================
۱. phpMyAdmin → Import همان فایل Export مرحلهٔ بکاپ.
۲. File Manager → zip بکاپ را Extract کنید روی همان پوشه.
۳. به من بگویید چه پیامی دیدید.


ح) یادآوری
==========
- joma.sql را Import نکنید.
- config.php را عوض نکنید.
- رمز دیتابیس را برای کسی نفرستید.

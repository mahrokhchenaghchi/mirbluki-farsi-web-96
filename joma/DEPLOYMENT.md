# استقرار جوما

محل نهایی پیشنهادی: `https://mirbolouki.com/joma`

**فعلاً Deploy انجام نشده است.**

1. پوشه `joma` را در `public_html/joma` بگذارید.
2. طبق `INSTALLATION.md` دیتابیس را Import کنید یا storage=file بماند.
3. `base_url` را `/joma` بگذارید.
4. `install.php` را پس از نصب حذف کنید.

جوما از سایت اصلی و سیستم نوبت‌دهی جداست.

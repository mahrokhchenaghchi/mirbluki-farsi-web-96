# پست ۱۰ اسلایدی RTL برای اینستاگرام — JOMA

این پوشه شامل ۱۰ تصویر PNG آماده‌ی کاروسل اینستاگرام با ابعاد `1080 × 1350` (نسبت 4:5) است.

## ترتیب انتشار

از `JOMA-Post-10Slides-01.png` تا `JOMA-Post-10Slides-10.png` به همان ترتیب آپلود کنید.

## خط داستانی

شروع نکردن → امید و شکست دوباره → خودسرزنشی → فاصله‌ی دانستن و انجام دادن → مشاهده → داده‌ی واقعی → الگوها → جغد دانا → JOMA → تأمل.

## کپشن پیشنهادی

چند بار با خودت گفتی «از شنبه شروع می‌کنم» و شنبه رسید، اما هیچ‌چیز تغییر نکرد؟

مشکل همیشه تنبلی یا بی‌ارادگی نیست. گاهی فقط رفتارهایمان را آن‌قدر دقیق ندیده‌ایم که بتوانیم الگوی پشت آن‌ها را بفهمیم.

به جای سرزنش، یک لحظه مکث کن: امروز چه شد؟ چه چیزی کمکت کرد؟ کجا متوقف شدی؟

JOMA برای همین ساخته شده؛ تا برنامه‌ریزی کنی، عملکرد و حالت را ثبت کنی، عادت‌هایت را پیگیری کنی و آرام‌آرام مسیر خودت را بشناسی.

**قبل از تغییر، خودت را بدون قضاوت ببین.**

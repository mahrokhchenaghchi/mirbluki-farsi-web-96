00-راهنما — بستهٔ نهایی جوما (نسخهٔ ۷)
=====================================================================
این بسته، همهٔ کارها را یک‌جا دارد: چهار فاز طرح تازه + همهٔ قابلیت‌های ساخته‌شده.
مسیر نصب: joma.mirbolouki.com/test   ·   فقط روی تست   ·   سایت اصلی دست‌نخورده.

──────────────────────────────────────────────
۱) این بسته را چطور نصب کنم؟ (۵ دقیقه)
──────────────────────────────────────────────
۱) در cPanel → File Manager برو به پوشهٔ ساب‌دامین joma.mirbolouki.com
   (همان پوشه‌ای که index.php سایت اصلی داخلش است).
۲) اگر نسخهٔ قبلی را نصب کرده‌ای: پوشهٔ «test» را پاک نکن؛ فایل‌ها را جای‌گزین می‌کنیم.
   اگر از صفر می‌خواهی: پوشهٔ «test» را کامل پاک کن.
۳) دکمهٔ Upload → فایل JOMA-TEST-PACK-v4.zip را آپلود کن.
۴) روی فایل zip راست‌کلیک → Extract → مسیر را دست نزن → Extract File
   نتیجه: یک پوشهٔ «test» ساخته/به‌روز می‌شود و همه‌چیز داخل آن است.
   ⚠️ هیچ‌وقت محتویات داخل test را به ریشهٔ سایت اصلی کپی نکن.
۵) در مرورگر این آدرس را باز کن:
      https://joma.mirbolouki.com/test/_SEED-DEMO.php
   این صفحه سه حساب نمونه + برنامهٔ این ماه + دو هفته ثبت + یک ارتباط هم‌مسیر می‌سازد.
   (اگر قبلاً ساخته‌ای، همان داده سرجایش می‌ماند و کاری خراب نمی‌شود.)
۶) همان فایل را پاک کن: داخل پوشهٔ test → _SEED-DEMO.php → Delete
۷) ورود: https://joma.mirbolouki.com/test/index.php?p=login
۸) تمام. (هیچ نصب، هیچ ری‌استارت، و در حالت فایل هیچ چیزی در دیتابیس لازم نیست.)

──────────────────────────────────────────────
۲) دیتابیس: چه چیزی باید اجرا کنم؟  (پاسخ کوتاه: هیچ‌چیز)
──────────────────────────────────────────────
· این بسته طوری تنظیم شده که با «فایل» کار کند (storage = file) و به هیچ دیتابیسی وصل نشود.
  پس نه SQL لازم است، نه جدول تازه، نه ستون تازه.
· اگر روزی خواستی همین کد روی سایت اصلی با MySQL اجرا شود، آن‌وقت:
   – جدول‌های اصلی از قبل در joma.sql هستند.
   – سه قابلیت این بسته (کد بازیابی رمز · آب پیش‌نویس/قطعی · نام جوجه · دیده‌شدن دفترچه ·
     درخواست حذف حساب) از یک جدول کلید/مقدار استفاده می‌کنند: joma_settings
   – اگر آن جدول در دیتابیس نبود، فایل اختیاری این را یک‌بار اجرا کن:
       اختیاری-1-joma_settings.sql   (فقط CREATE TABLE IF NOT EXISTS — بی‌خطر و ADD-ONLY)
   – هیچ UPDATE/DELETE روی دادهٔ کاربران لازم نیست.
· config/config.php سایت اصلی هیچ‌وقت با این بسته عوض نمی‌شود (کانفیگ داخل test جداست).

۳.۵) اول از همه: بررسی سلامت نصب (۱۵ ثانیه)
──────────────────────────────────────────────
این آدرس را باز کن:  https://joma.mirbolouki.com/test/health.php
یک جدول می‌بینی: نسخهٔ PHP · افزونه‌های لازم · نوشتنی بودن پوشه‌ها · فایل‌های اصلی ·
حفاظت پوشه‌ها · کتابخانهٔ ۱۰۷ فعالیتی · ساعت سرور.

این صفحه هیچ‌چیز را تغییر نمی‌دهد.

──────────────────────────────────────────────
۴) چه چیزی را ببینم؟ (ترتیب پیشنهادی، ۵ دقیقه)
──────────────────────────────────────────────
۱) صفحهٔ معرفی: https://joma.mirbolouki.com/test/index.php?p=home
   → باید فقط «یک» نوار بالا باشد (جغد + ورود + شروع رایگان) و قاب «یک روز در جوما» صاف.
۲) ثبت‌نام (پنج گام): index.php?p=register → معرفی · شغل · نام کاربری · رمز · تماس و تأیید
۳) ورود با maryam → خانهٔ من: «قدم بعدی»، حال امروز، چهار عدد، قدم‌های امروز، جوجه.
۴) کارهای امروز: کارت لیوان آب (لمس لیوان = پر · لمس دوبارهٔ همان لیوان = خالی، بی‌صدا ·
   کلید «صدای آب» پیش‌فرض خاموش) + دکمهٔ «ثبت نهایی» + کارت تمرین تنفس ۴-۷-۸.
۵) حال من: پنج پرسش یکی‌یکی + گام ششم (جملهٔ اختیاری). برگشت به عقب مجاز است.
۶) جوجهٔ من: روی جوجه بزن (واکنش + صدا اگر روشن کنی)، «بخوابانش» را امتحان کن.
۷) گزارش‌ها: هر ده تب یک نمودار دارد؛ اگر داده نباشد پیام روشن می‌آید (نه صفحهٔ خراب).
۸) دفترچهٔ جوما: بینش‌ها با دکمهٔ «این برداشت از کجا آمده؟» + نوشته‌های خودت.
۹) برنامهٔ من: کارت «دورهٔ نو با همین فعالیت‌ها» (کپی برنامه به ماه بعد).
۱۰) حقوق داده: خروجی گزارش/CSV/JSON + درخواست حذف حساب با مهلت.
۱۱) با modir: کنسول مدیر → وضعیت نصب، کاربران، و «صدور کد بازیابی رمز».
۱۲) با moshaver: هم‌مسیر → میز کار مشاور (یادداشت خصوصی مراجع دیده نمی‌شود).

──────────────────────────────────────────────
۵) اگر خطا دیدی
──────────────────────────────────────────────
· خطای PHP دربارهٔ نسخه: cPanel → MultiPHP Manager → دامنه را روی PHP 7.4 بگذار.
· صفحهٔ سفید: مطمئن شو پوشهٔ test/data قابل نوشتن است و فایل assets/css/joma-v2.css آپلود شده.
· بازگشت کامل: پوشهٔ test را پاک کن (سایت اصلی دست‌نخورده می‌ماند).
· پاک‌کردن کل کپی تست: فقط پوشهٔ test را Delete کن.

──────────────────────────────────────────────
۶) صداها (تمرین تنفس · لیوان آب · جوجه)
──────────────────────────────────────────────
· صدای راهنمای تنفس: سه فایل در test/assets/audio/ (br-in · br-hold · br-out) — پیش‌فرض خاموش.
· صدای لیوان آب: با مرورگر ساخته می‌شود؛ پیش‌فرض خاموش. خالی‌کردن لیوان همیشه بی‌صداست.
· صدای جوجه (جیک · خرخر · خروپف · خمیازه): با مرورگر ساخته می‌شود — پیش‌فرض خاموش.
· اگر مرورگر صدا را پخش نکند، همان جمله‌ها روی صفحه نوشته می‌شوند.
